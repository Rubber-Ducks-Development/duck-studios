# Documentation image sources

Captured October 15, 2026, from Duck Studio 2.1.2 application controls.

| Image | Origin and data |
| --- | --- |
| `tattoos.png` | Actual `TattooWindow` WPF control tree rendered using WPF RenderTargetBitmap. The project owner's existing `Editor/Assets/AppIconSource.png` is linked as demonstration tattoo artwork. |
| `project-settings.png` | Actual `SettingsWindow` WPF controls rendered using WPF RenderTargetBitmap with original demonstration collection values. No GTA installation, personal project or private filesystem path is displayed. |

The capture harness used an isolated application data directory with update checks
disabled. No product controls, feature labels or status messages were drawn onto the
images. The screenshots are examples of the controls, not proof of GTA/FiveM runtime
behavior. The supplied duck artwork remains the project owner's asset.
